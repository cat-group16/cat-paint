# cat-paint
# 🐾 Cat Paint v1.0.4

Un'app per disegnare divertente e colorata a tema gatto, ottimizzata per Android e testata su diversi dispositivi (inclusi Mi Max 3 e Tablet Samsung con Android 12).

## ✨ Novità della Versione 1.0.4
*   **Fix Critico Android 12**: Risolto il crash all'avvio riducendo l'API dalla 37 alla 34 per una stabilità perfetta su Android 12+.
*   **Menu Principale**: Nuova interfaccia di benvenuto.
*   **Toolbar Avanzata**: Controlli spostati in alto per più spazio al disegno.
*   **Strumento Testo**: Scrivi direttamente sui tuoi disegni.
*   **Esportazione Multiformato**: Salva le tue opere in PNG, JPG o come documento PDF! 📄
*   **Cat Layout**: Decorazioni gattose attive di default.

## 🚀 Caratteristiche
*   Disegno a mano libera con vari colori.
*   Strumento Gomma.
*   Importazione di immagini e PDF come sfondo.
*   Widget per la Home Screen con anteprima in tempo reale.

## 🛠️ Note Tecniche
*   **Min SDK**: 29 (Android 10)
*   **Target SDK**: 34 (Android 14)
*   **Linguaggio**: Java / XML
